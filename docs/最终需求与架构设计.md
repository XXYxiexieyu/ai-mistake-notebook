# 高三错题本应用：最终需求与架构设计

版本：v2.6
状态：0.7.1 预览版已实现；0.7.0 已完成小米 15、小米 13 双机主要流程验证，0.7.1 待实机回归
目标版本：个人使用安卓预览版

## 1. 产品范围

### 1.1 用户与平台

- 仅供一名高三学生使用，首版无账号、无登录、无多用户隔离。
- 仅支持安卓，目标设备为未 Root 的小米 15 和小米 13。
- 两台手机的数据互相独立，不自动同步。
- 首版不包含 iOS、网页端、微信小程序或平板专属界面。
- 暂不上架应用商店；功能完善后再考虑上架及相关合规工作。

### 1.2 学习范围

- 科目：语文、数学、英语、物理、化学、生物。
- 地区与考试风格：北京高考，参考北京西城区命题风格。
- 题型归纳范围：`E:\学习` 中的 2022–2026 年北京高考真题。
- 不包含英语听力。

### 1.3 教材范围

共 35 册：

| 科目 | 教材 |
|---|---|
| 语文 | 统编版（人教社出版）必修上册、必修下册、选择性必修上册、中册、下册 |
| 数学 | 人教 B 版 2019 必修第一至第四册、选择性必修第一至第三册 |
| 英语 | 北师大版 2019 必修第一至第三册、选择性必修第一至第四册 |
| 物理 | 人教版 2019 必修第一至第三册、选择性必修第一至第三册 |
| 化学 | 人教版 2019 必修第一、二册、选择性必修 1 化学反应原理、2 物质结构与性质、3 有机化学基础 |
| 生物 | 人教版 2019 必修 1 分子与细胞、必修 2 遗传与进化、选择性必修 1 稳态与调节、2 生物与环境、3 生物技术与工程 |

知识树从公开教材目录资料（如电子课本网）整理后内置到应用中，不在应用运行时实时抓取网页，避免网站变化、断网和页面解析导致功能失效。知识树支持用户校对、修改和增加自定义知识点。

## 2. 核心架构

```text
安卓应用
├─ 拍照 / 相册批量导入
├─ 自动分题 / 手动多框选 / 透视校正
├─ 本地图片存储
├─ Room 本地数据库
├─ WorkManager 后台上传与重试
├─ DeepSeek 官方 API 调用层
├─ AI 结果编辑、重复题合并
├─ 按科目 / 书目 / 单元 / 知识点 / 时间浏览
├─ 重考组卷、答题、AI 判分、可选评分调整
├─ 图表统计
├─ 离线数学符号库与 LaTeX / Unicode 显示转换
├─ PDF 错误知识点报告
└─ ZIP 换机备份与合并导入
```

首版不使用自有服务器。应用直接通过 HTTPS 调用 DeepSeek 官方 API，API 密钥由用户填写并存入 Android Keystore。

系统关闭安卓云备份，避免手机系统将应用数据自动同步到云服务。数据迁移只使用用户主动导出的 ZIP 文件。

### 2.1 离线运行要求

应用采用“本地数据库为唯一事实来源”的设计。启动、分类查看和已有数据管理不得依赖网络、账号、服务器健康检查或在线知识树。

未配置 API 密钥、API 密钥失效或 AI 服务不可用时，应用也必须正常进入并使用全部本地分类查看功能。

必须离线可用的功能：

- 启动应用并进入首页、错题本、待复习和设置页面。
- 按科目、教材书目、单元、章节、知识点、题型、数学专题、错误原因、拍摄时间和复习状态分类、筛选和排序。
- 打开错题详情，查看本地题目图片、原作答证据、AI 分析、用户修正和重考历史。
- 新建草稿、手动填写科目与知识树分类、修改标签、修改复习状态和删除本地数据。
- 使用内置知识树，包括 35 册教材的书目、单元和章节。
- 从已有错题中按科目和拍摄日期生成重考测试，离线录入文字或图片答案并保存进度。
- 从本地数据计算统计图表，统计结果不等待 AI 服务。
- 使用内置数学符号库，并把 AI 返回的常见 LaTeX 或上标/下标写法转换为可读符号。
- 生成仅依赖本地结构化数据的 PDF 报告。
- 导出和合并导入普通 ZIP 备份。

依赖网络或 AI 的功能：

- AI 自动分题、题目识别、答案与解析生成。
- 基于原作答证据的错因分析。
- 重考答案的 AI 判分。

网络不可用时的处理：

- 拍照或导入后先完整写入本地数据库和图片目录，状态标记为“等待分析”，不得因上传失败丢失原始内容。
- 用户可以在离线状态下为等待分析的错题手动指定科目、书目、单元、章节、知识点和题型。
- WorkManager 只在满足网络约束时执行 AI 任务；恢复网络后自动继续。
- 重考答案可以离线保存为“等待判分”，恢复网络后提交 AI；用户也可以直接手动判定。
- AI 请求失败只影响对应任务状态，不得阻止其他本地数据浏览和分类功能。

## 4. 图片录入流程

1. 用户可以拍照，也可以从相册导入。
2. 支持一次导入多张图片。
3. 支持手动逐题框选四角并校正透视。
4. 支持 AI 自动识别题目区域；识别结果必须可手动调整。
5. 单张图片最多生成 10 道题，单次批量最多 50 道题。
6. 每道裁剪题生成独立错题记录，并关联共同的原图。
7. 图片和后台上传任务先保存在本地；网络不可用时等待重试。
8. 应用进入后台后，WorkManager 继续处理任务。小米系统限制后台任务时，应提示用户允许必要权限或保持任务页面。
9. 每题可选择性补充原作答证据，包括错误答案、解题过程或草稿照片，也可以输入文字。
10. 用户可以标记错误发生在某个小问或关键步骤；不提供作答证据时仍可正常收录题目。
11. 离线时仍可完成手动裁剪、手动分类和本地保存；自动分题与 AI 识别进入等待队列。

### 4.1 整页自动识别错题

整页扫描作为独立入口，继续复用“本地图片 + WorkManager + DeepSeek 官方 API”的架构：

1. 用户拍摄或选择一整页作业、试卷。
2. 图片先完整保存到本地，创建整页扫描任务。
3. 联网后由 DeepSeek 检查题目、作答区域和答案附近的批改痕迹。
4. 错题证据包括蓝色、紫色、红色、绿色等不同颜色笔的叉号、圈划、删除线、订正、扣分标记、失分标记和被改写的答案。
5. 扫描前在手机本地生成彩色笔迹增强图，将蓝笔等彩色笔迹从灰色印刷内容中分离，并与原图一起交给 AI。
6. 普通下划线、高亮和单次红勾不作为判错依据；无明确批改证据时不自动判错。
7. 单页最多识别 10 道错题，AI 返回归一化题目区域。
8. 手机按区域裁题，把每道错题写入本地数据库，并额外保存 `evidenceType` 和 `wrongEvidence`。
9. 重复题按已有规则确认或合并；识别结果可在错题详情中人工修正。
10. 任务状态为等待处理、分析中、完成或失败，关闭页面后任务仍由 WorkManager 继续。
11. 未配置 API 密钥或断网时，整页原图保留在本地，等待用户配置或联网后继续。
12. 用户启动扫描后进入独立进度页，显示当前页保存、彩笔增强、AI 分析、裁题入库和完成状态，并可转到后台。
13. 单次扫描最多支持 10 页，页面顺序可调整；跨页大题通过多个页面区域 segment 返回。
14. 手机端按页面顺序裁切跨页区域，再纵向拼接为一张题目图，只写入一条错题记录。
15. 批量导入页支持一键对全部未处理图片执行 AI 分题，展示每一道分题预览和独立删除入口。
16. 手机单题裁剪支持四角透视调整，以及四条边中点的平行移动抓手。
17. 所有 AI 分题流程必须先展示具体错题依据；选项不同、答案解析错误、异色笔订正或扣分标记才可作为判错依据。
18. 单道错题裁剪必须包含完整题干、图表、选项和对应作答，不夹带相邻题目。
19. 错题详情按“题目 → 答案解析 → AI 提问 → 题目照片 → 知识点知识网”排列。
20. 点击知识点打开独立知识点错题目录。
21. 首页加号上方显示整页扫描、批量 AI 分题及待分析任务进度。
22. 裁剪页使用独立底部操作栏放置“取消”和“使用此框选”，并保留固定底部安全留白，避免依赖厂商 Dialog Insets。
23. 首页加号上方常驻处理进度球，尺寸与添加按钮一致，仅显示完成与剩余数量；点击进入添加历史和处理进度页面。
24. 全部 AI 分题和整页扫描结果均先进入错题审查，确认后才计入正式错题本。
25. 新增错题使用底部控制栏正中的圆形加号；点击后先选择单题导入或批量导入。
26. 整页扫描作为批量导入的一种方式，不再在首页单独暴露入口。
27. 批量导入和整页扫描默认使用 AI 自动识别学科，也可手动指定科目。
28. 底部导航从左到右为：错题本、单词本、添加错题、总结、设置；重考移动到错题本右上角。
29. 添加方式增加英语阅读查词，可上传最多 5 页阅读或完型篇目。
30. 查词功能只识别手写圈画、划线单词，并把翻译和上下文写入本地单词本。

## 5. AI 分析

### 5.1 服务与模型

- 只接入 DeepSeek 官方 API。
- 默认模型：`deepseek-flash`。
- 设置中可切换至质量更高的 `deepseek-v4-pro`。
- API 密钥可修改，不写入代码或日志。
- Token 用量和调用错误应可查看，但不在首版实现费用结算。

### 5.2 每道错题的分析字段

- 识别后的完整题目文字和公式
- 正确答案
- 解题过程与解析
- 科目
- 教材书目、单元、章节
- 一个或多个知识点
- 科目专属题型
- 数学等科目的题目专题
- 错误原因或“未补充错因”状态
- 难度
- 各项置信度
- 是否建议人工复核

AI 识别结果默认直接作为当前值使用。人工修改仅作为可选入口，不要求用户逐项确认，也不主动显示纠错提醒。无法映射到知识树的知识点标记为“未匹配”。

### 5.3 原作答与错因

- 原作答证据是可选内容，不强制影响题目收录。
- 用户可为整道题、某个小问或关键步骤添加文字或图片证据。
- 提供作答证据后，可以请求 AI 基于实际答案和解题过程定位错误，AI 结果默认直接生效。
- 用户可以主动进入编辑页面修改错因，同时保留 AI 原始结果作为参考。
- 用户可以选择“不补充错因”；此时错因字段保持为空，不展示推测性结论，也不参与错因分布统计。
- 未提供原作答时可以生成候选错因，但必须明确标注为推测，不能作为确定诊断。
- 删除错题时，原作答文字、草稿图片和相关分析一并删除。

### 5.4 结构化输出

API 返回必须经过 JSON 结构校验。无法解析时自动重试一次；仍失败则保存错误状态，不能把未校验文本直接写入错题记录。

### 5.5 知识点与教材知识网映射

- AI 在题目分析完成后输出知识点名称和可能教材位置。
- 普通上传和整页扫描在分析时同时提取学生原始作答、草稿及错误步骤，自动填入原作答字段。
- 本地匹配器在对应科目的 35 册教材树中查找书目、单元和章节，不依赖联网知识库。
- 上传表单的书目、单元、章节和题型默认使用 AI 识别结果，人工选择仅作为可选操作。
- 精确或包含匹配标记为“知识网匹配”，模糊匹配标记为“知识网近似匹配”。
- 无法匹配的知识点保留为“未匹配”，不伪造教材位置，也不主动提醒纠错。
- 错题详情页展示每个知识点的完整知识网路径。
- 用户修改书目、单元、章节或知识点后，本地重新计算映射。
- 整页扫描和手工上传都使用同一套知识点映射规则。

### 5.6 针对题目提问

- 错题详情页提供“针对本题向 AI 提问”入口。
- 每次请求自动附带当前题目照片、题目文字、标准答案、解析、错因、批改证据和知识网定位。
- 用户可以连续追问，也可以附加一张新的题目或草稿图片。
- 用户消息、AI 回复、附加图片和失败状态全部保存在本地数据库。
- 无网络时消息与待回复状态保留，恢复联网后由 WorkManager 继续。
- 删除错题时同时删除该题问答历史和聊天附加图片。
- 问答历史包含在普通 ZIP 换机备份中。

## 7. 错题组织与排序

知识树层级：

```text
科目
└─ 教材书目
   └─ 单元
      └─ 章节
         └─ 知识点
            └─ 错题
```

错题支持按以下条件筛选、组合和排序：

- 科目
- 教材书目
- 单元
- 章节
- 知识点
- 题型
- 数学专题
- 错误原因
- 拍摄时间
- 复习状态
- 错误次数
- 最近出错时间

默认按拍摄时间倒序排列，并保留用户最后一次排序选择。

## 8. 重复题合并

1. 新错题提交后，应用使用图片相似度、题目文字和知识点寻找可能重复题。
2. 不自动静默合并，先标记“可能重复”。
3. 用户确认后合并为一个主错题。
4. 错误次数累计，保留每次拍摄时间、图片和重考结果。
5. 用户可以拆分误合并的记录。

## 9. 复习与重考

### 9.1 状态

主状态：

- 未复习
- 已复习
- 重考通过

重考未通过时回到“已复习”，并保留本次失败记录。列表可筛选“曾经重考未通过”。

### 9.2 生成重考测试

- 从“已复习”的错题中组卷。
- 按科目和拍摄日期范围筛选。
- 用户可以逐题勾选或全选。
- 使用原错题组成测试，不生成同类型新题。
- 默认按拍摄时间排序。
- 单次组卷数量受本地性能和 API 限制约束。

### 9.3 重考过程

- 逐题显示原题，不显示答案和解析。
- 答案支持文字输入和拍照提交。
- 不设时间限制，但记录整套测试和每道题的实际用时。
- 用户提交后由 AI 判定为正确、部分正确或错误，并给出判分说明。
- AI 判定默认直接生效，用户可选调整判定结果和说明。
- 每道题独立更新状态。
- 中途退出保存进度，可以继续未完成的测试。

## 10. 首页和图表

总结页面采用三级视图：

- 全部总结：所有已收录错题的总体图表和排行。
- 各科目总结：六个科目分别统计错题数量、近 30 天、复习状态、易错知识点和错因。
- 各书目总结：按教材册次聚合，并支持按科目筛选。

设置页版本号从 Android 构建配置的 `VERSION_NAME` 和 `VERSION_CODE` 动态读取，不在界面中硬编码。

首页入口：

- 按科目分类
- 按教材书目、单元、章节和知识点浏览
- 按题型浏览
- 分析中或分析失败的任务
- 待复习错题
- 重考测试
- 知识点总结图表
- 易错知识点梳理
- 设置、导出和换机

统计图表：

- 各科错题数量
- 各书目和单元错题分布
- 题型分布
- 错误原因分布
- 未补充错因数量
- 复习状态分布
- 最近 30 天新增错题趋势
- 知识点错题数量排行
- 重考失败次数排行
- 易错知识点清单

易错知识点不使用不透明的综合分数，而直接展示累计错误次数、重考失败次数和最近 30 天新增次数。

## 11. PDF 报告

- 仅导出 PDF。
- 按“科目 → 书目 → 单元 → 错误知识点”组织。
- 包含错题数量、已记录错误原因分布、未补充错因数量、复习状态统计和知识点总结。
- 不包含具体题目、题目图片、答案或解题过程。
- 支持选择科目和时间范围。
- 报告内容优先由本地已保存数据分析生成，不因临时断网而完全不可用。

## 12. 一年提醒

- 触发对象：已重考通过且通过时间已满 365 天的错题。
- 只提醒，不自动删除。
- 提醒时支持：
  - 删除当前错题的全部数据；
  - 删除全部已满一年且重考通过的错题数据。
- 不在此入口提供“清空整个错题本”。
- 删除同时清理题目记录、关联图片、原作答证据、AI 分析和重考记录。
- 设置中可关闭全部一年提醒。

## 13. 换机备份

- 使用普通 ZIP，不加密。
- 内容包括数据库导出、题目图片、原作答证据、AI 分析结果、重考记录、用户修改和知识树自定义内容。
- API 密钥不进入备份。
- 导入只支持合并，不覆盖本机数据。
- 导入前显示预计新增、重复和冲突数量。
- 遇到重复题时累计错误次数并保留两份拍摄记录。
- 所有导入操作在事务中完成，失败时不能留下半份数据。

## 14. 隐私与安全

- 无应用启动密码，无指纹或面容锁。
- 图片会发送给 DeepSeek 官方 API 进行识别和分析；用户已接受该数据流向。
- 应用自身不使用服务器长期保存图片。
- API 密钥存入 Android Keystore。
- 不记录包含密钥、题目图片或答案的调试日志。
- 禁用 Android 系统自动云备份，数据迁移通过手动 ZIP 完成。
- 用户导出到公共目录后的 ZIP 不受应用保护，需要用户自行保管。

## 15. 主要页面

1. 首页：待复习、薄弱知识点、最近错题和分析任务状态。
2. 拍照与导入：相机、相册、多图队列。
3. 分题与裁剪：自动框选、手动四角调整、透视校正。
4. 处理队列：上传、分析、失败重试。
5. 批量确认：AI 结果修改、科目和知识树校正。
6. 错题本：分类、筛选、排序、详情。
7. 错题详情：原图、题目、答案、解析、知识树、原作答证据、错因、历史记录。
8. 重考组卷：科目、日期范围、选题。
9. 重考答题：原题、文字或图片答案、提交。
10. 重考结果：AI 判定、可选评分调整、状态更新。
11. 统计：图表和易错知识点。
12. 导出与换机：PDF、ZIP 导出、合并导入。
13. 设置：API 密钥、模型切换、一年提醒、存储管理。

界面风格首版采用浅色、清爽的学习风格；基础功能完善后再增加自定义主题和样式。

## 16. 预览版验收标准

- 能在小米 15、小米 13 上安装并正常运行。
- 首次启动断网时，应用仍能进入首页并使用内置的 35 册教材知识树。
- 未配置或填写无效 API 密钥时，已有错题仍可正常浏览和分类。
- 断网时，已有错题仍可按科目、书目、单元、章节、知识点、题型、拍摄日期和复习状态查看、筛选与排序。
- 断网时，本地图片和详情可以正常打开，统计图表和 PDF 可以从本地数据生成。
- 断网导入的新错题不会丢失，并可由用户手动分类，等待恢复网络后再进行 AI 分析。
- 能拍照或从相册导入，支持多题和多图。
- 能自动分题，也能手动框选和校正。
- 关闭页面后能后台上传和重试。
- 能调用 DeepSeek 官方 API，默认使用 `deepseek-flash`，可切换模型。
- 能保存并编辑完整 AI 分析结果。
- 能选择性补充错误答案、解题过程或草稿，并支持标记具体小问或步骤。
- 能选择“不补充错因”，此时不显示推测错因且不计入错因统计。
- 能按六科题型、教材书目、单元、知识点和时间分类。
- 能识别并人工确认合并重复题。
- 能按科目与拍摄日期生成重考测试，隐藏答案、记录用时、AI 判分，并提供可选评分调整。
- 复习状态能按既定流程更新并保留失败记录。
- 能显示约定的统计图表和易错知识点列表。
- 能导出不含具体题目的 PDF 错误知识点报告。
- 能生成普通 ZIP 并通过合并方式换机导入。
- 能对一年前通过的错题提醒删除，并可在设置中关闭。
